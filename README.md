# 🚀 Clario – Productivity Web Platform

Clario is a modern full-stack productivity platform built with the MERN stack to help users organize their daily activities through an intuitive and feature-rich interface. The application combines multiple productivity tools into a single platform, enabling users to efficiently manage tasks, habits, notes, expenses, and more.

🌐 **Live Demo:** https://clario-one.onrender.com/

---

## ✨ Features

- 🔐 Secure user authentication using JWT
- ✅ Task management with progress tracking
- 🔥 Habit tracker for building daily routines
- 📝 Notes management
- ⏱️ Pomodoro timer for focused work sessions
- 💰 Expense tracker
- 📚 Personal book library
- 🤖 AI-powered chatbot
- 📄 AI text summarizer
- 📱 Responsive design for desktop and mobile devices
